# セットアップガイド（実行手順書）

## 前提条件

- Python 3.10 以上
- pip
- Anthropic API キー（https://console.anthropic.com/ で取得）

---

## Step 1: 仮想環境の作成

```bash
# プロジェクトルートで実行
cd c:\project\practice\model_practice

# 仮想環境を作成（すでに venv/ があれば省略可）
python -m venv venv

# 仮想環境を有効化 (Windows)
venv\Scripts\activate

# 仮想環境を有効化 (Mac/Linux)
source venv/bin/activate
```

---

## Step 2: 依存ライブラリのインストール

```bash
pip install -r requirements.txt
```

> **注意**: sentence-transformers のインストールに数分かかることがあります。
> また、初回起動時に埋め込みモデル（約270MB）がダウンロードされます。

---

## Step 3: 環境変数の設定

```bash
# .env.example をコピーして .env を作成
copy .env.example .env      # Windows
# cp .env.example .env      # Mac/Linux
```

`.env` ファイルを開いて API キーを設定してください：

```
ANTHROPIC_API_KEY=sk-ant-あなたのAPIキー
```

---

## Step 4: RAG インデックスの構築

```bash
python main.py --mode build-index
```

実行すると以下が行われます：
1. `knowledge_base/` のドキュメントを読み込む
2. テキストをチャンクに分割する
3. 埋め込みベクトルを生成する（初回はモデルをダウンロード）
4. `vector_store/` にインデックスを保存する

**成功時の出力例：**
```
📄 ドキュメントを読み込み中...
   → 3 ファイル読み込み完了
✂️  テキストをチャンクに分割中...
   → 47 チャンク生成
🔢 埋め込みベクトルを生成中...
   → ベクトル次元数: 768
💾 FAISS インデックスを構築・保存中...
✅ インデックス構築完了 — 47 チャンク
```

## Step 6: API モードで起動（オプション）

```bash
python main.py --mode api
```

起動後、ブラウザで以下にアクセスできます：

- Swagger UI: http://localhost:8000/docs
- ヘルスチェック: http://localhost:8000/health

**API でチャットする例（curl）:**

```bash
curl -X POST http://localhost:8000/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "広告費50万円なら売上はいくら？", "session_id": "test"}'
```

## ナレッジベースにドキュメントを追加する方法

1. `knowledge_base/` フォルダにファイルを置く（対応形式: .txt, .md, .pdf, .csv）
2. インデックスを再構築する：

```bash
python main.py --mode build-index
```

## トラブルシューティング

### Q: `ANTHROPIC_API_KEY が設定されていません` エラー

`.env` ファイルに正しく API キーが設定されているか確認してください。
`.env` ファイルが存在しない場合は Step 3 を実施してください。

### Q: `faiss` のインストールが失敗する（Windows）

```bash
pip install faiss-cpu --no-build-isolation
```

### Q: 初回起動が遅い

sentence-transformers が埋め込みモデルをダウンロードしています。
ネット環境にもよりますが 2〜5 分かかることがあります。2 回目以降は速い。

### Q: インデックスを作り直したい

```bash
# vector_store/ フォルダを削除してから再構築
rmdir /s /q vector_store   # Windows
# rm -rf vector_store      # Mac/Linux
python main.py --mode build-index
```

### Q: 思考ログを表示したくない

現在、`cli.py` の `build_agent(verbose=True)` を `verbose=False` に変更することで
非表示にできます。
