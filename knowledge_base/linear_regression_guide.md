# 線形回帰とニューラルネットワークの基礎

## このプロジェクトの線形回帰モデル

`src/model.py` の `LinearRegression` クラスは、
広告費（ad_budget）から売上（sales）を予測するモデルです。

### モデルの数式

```
ŷ = w × x + b

ŷ: 予測値（売上）
x: 入力（広告費）
w: 重み（weight）
b: バイアス（bias）
```

### 損失関数（MSE）

```
MSE = (1/N) × Σ(ŷᵢ - yᵢ)²

N: サンプル数
ŷᵢ: 予測値
yᵢ: 正解値
```

## 勾配降下法（Gradient Descent）

損失を最小化するパラメータ w, b を求める最適化アルゴリズム。

### 更新式

```
∂MSE/∂w = (2/N) × Σ(ŷᵢ - yᵢ) × xᵢ   ← 重みの勾配
∂MSE/∂b = (2/N) × Σ(ŷᵢ - yᵢ)         ← バイアスの勾配

w ← w - lr × ∂MSE/∂w
b ← b - lr × ∂MSE/∂b

lr: 学習率（learning rate）
```

### 学習率の選び方

| 学習率 | 挙動                              |
|--------|-----------------------------------|
| 大きすぎ | 損失が発散（振動・爆発）         |
| 適切   | 滑らかに収束                      |
| 小さすぎ | 収束が遅い                       |

このプロジェクトの推奨: `lr = 0.0001`, `epochs = 5000`

## データセット（data/sales_data.csv）

生成式:
```
sales = 5 + 2.5 × ad_budget + ノイズ（N(0, 10)）
```

- サンプル数: 100件
- ad_budget の範囲: 0〜100万円
- ノイズにより完全な線形ではなく現実的な散らばりを持つ

## 評価指標

### R²スコア（決定係数）
```
R² = 1 - SS_res / SS_tot

SS_res = Σ(yᵢ - ŷᵢ)²  （残差の二乗和）
SS_tot = Σ(yᵢ - ȳ)²   （全変動）
```

| R² 値  | 解釈                |
|--------|---------------------|
| 1.0    | 完全予測            |
| 0.9〜  | 非常に良い          |
| 0.7〜  | まずまず            |
| 0.7未満 | 要改善             |

### MAE（平均絶対誤差）
```
MAE = (1/N) × Σ|yᵢ - ŷᵢ|
```
外れ値に鈍感で解釈しやすい。

### RMSE（二乗平均平方根誤差）
```
RMSE = √MSE
```
誤差の単位が元データと同じになる。

## 線形回帰からニューラルネットワークへ

線形回帰は、ニューラルネットワークの最も単純な形と見なせる。

```
線形回帰:   x → [w×x + b] → ŷ           (活性化関数なし)
NN(1層):    x → [w×x + b] → ReLU → ŷ   (活性化関数あり)
NN(多層):   x → Layer1 → Layer2 → ... → ŷ
```

活性化関数（ReLU: max(0, x)）を追加することで
非線形な関係を学習できるようになる。
