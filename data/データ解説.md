# 練習用回帰モデルプロジェクトまとめ

## 1. データについて

### データ構造
| 列名        | 説明 |
|------------|------|
| ad_budget | 入力（広告費）。広告費が大きいほど売上が増える傾向がある。(万円設定) |
| sales     | 出力（売上）。広告費に比例した値にノイズを加えたもの。(万円設定) |

### データ例
| ad_budget       | sales          |
|----------------|----------------|
| 37.454011884736246 | 99.50550039422232 |
| 95.07143064099162  | 239.68850309782036 |
| 73.1993941811405   | 188.9160932182063  |
| 59.86584841970366  | 134.78893190325022 |
| 15.601864044243651 | 41.80794123223401  |
| 15.599452033620265 | 47.56975579916812  |

### 特徴
- 広告費が増えると売上も増える（線形傾向）
- 少しノイズがあるため、完全な直線ではない
- 実務では「入力が増えれば出力も増える傾向はあるが、データには揺らぎがある」というイメージ

---

## 2. 実務での前提

- データは **過去の実績データ** を想定
- 傾きや切片は未知 → モデルが学習して推定する
- データ件数は多く、まとめて処理する
- 欠損値や外れ値は確認・処理が必要
- モデルは意思決定や予測に使う

---

## 3. 回帰モデルの基本

### 単回帰の形
\[
\hat{y} = w \cdot x + b
\]

- \(x\) : 入力（広告費）
- \(y\) : 正解（売上）
- \(\hat{y}\) : 予測値
- \(w\) : 傾き（学習で推定）
- \(b\) : 切片（学習で推定）

### 損失関数（誤差の指標）
\[
\text{MSE} = \frac{1}{N} \sum_{i=1}^{N} (\hat{y}_i - y_i)^2
\]

- 平均二乗誤差 (MSE) を最小化するように w, b を調整する
- ビジネス上の損失感覚と合致するかも確認する

---

## 4. 学習の流れ（概念）

1. データ読み込み (X:入力, y:出力)
2. 初期値 w, b を設定
3. 予測値 \(\hat{y} = w*x + b\) を計算
4. MSE を計算
5. MSE を減らす方向に w, b を少しずつ更新
6. 4-5 を繰り返し最適値を探索
7. テストデータで精度確認
8. 必要に応じて改善（特徴量追加、正規化、学習率調整など）
